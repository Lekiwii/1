# CMP

Site vitrine de CMP, studio de développement : sites internet, applications iPhone, applications web et logiciels sur mesure.

Page unique (`index.html`) : 3D temps réel (Three.js), défilement fluide (Lenis) et animations au scroll (GSAP ScrollTrigger). Chaque envoi sur la branche publiée redéploie le site sur GitHub Pages (`.github/workflows/pages.yml`).
